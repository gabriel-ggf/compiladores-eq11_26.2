# Problemas Encontrados e Soluções Adotadas

Log de problemas técnicos relevantes durante o desenvolvimento e como
foram resolvidos. Este documento é um dos itens pedidos pela disciplina
para a entrega final (mostra o processo de resolução de problemas do
time, não só o resultado).

Formato sugerido por entrada:

## [dd/mm] Título curto do problema

**Contexto:** o que estava sendo feito quando o problema apareceu.

**Problema:** descrição do erro/comportamento inesperado.

**Solução:** o que foi feito para resolver (ou contornar).

**Aprendizado:** o que o time levou daqui para frente.
